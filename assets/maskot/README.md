# Asset maskot ChatGerCep

Kumpulan PNG transparan untuk Remotion dan konten ChatGerCep. Semua pose mempertahankan karakter robot, kaos hijau, dan emblem aplikasi.

## Isi

- `base/`: versi setengah badan dan full body.
- `ekspresi/`: senang, sedih, marah, kaget, bingung, berpikir.
- `pose/`: aktivitas HP, telepon, laptop, presentasi, gesture jempol, pose khusus untuk alur video hook, dan `lari-gercep-sprite.png` (sprite sheet lari 4 frame dengan efek listrik hijau, tanpa teks).

File dalam `pose/` dan `ekspresi/` adalah gambar full body dengan latar transparan.
